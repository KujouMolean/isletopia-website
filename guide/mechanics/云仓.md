# 云仓

云仓（CloudInventory）是跨岛屿、跨世界的云端仓库：把物资存进去，在任何开启云仓的岛屿上取出来，背包满了不用跑回家。

## 入口与前置

- 命令：`/cloudinventory`（别名 `/ci`、`/云仓`）。
- 前置：所在岛屿启用云仓特性（绝大多数常规岛屿默认启用；专家模式岛屿未启用）。
- 另有 GUI 入口：辅助功能界面（`/assists`）中的「云仓」。
- QQ 群内可用 `/云仓 [玩家]` 查看某玩家云仓的前 25 种物品（固定读取普通档案）。

## 命令一览

| 命令 | 功能 |
| --- | --- |
| `/ci List`（或 `/ci GUI`） | 打开云仓列表界面 |
| `/ci Get <物品> <数量>` | 取出物品，数量 1–1728，且不超过 37 组 |
| `/ci Put` | 打开 54 格「上传物品」容器，**关窗时结算入库** |
| `/ci Fill <物品>` | 用云仓库存把背包中的该物品补满（受背包空位与上限约束） |
| `/ci GetBox <物品>` | 消耗 1 个潜影盒 + 27 组该物品，直接产出一盒装满的潜影盒 |
| `/ci EnableAutoFill <物品>` | 开启自动填充：快捷栏与副手中该物品的未满堆叠自动补满 |
| `/ci DisableAutoFill` | 关闭自动填充 |
| `/ci TogglePin <物品>`（别名 `pin`） | 置顶/取消置顶（置顶物品排最前，带 ★ 标记） |
| `/ci textList` | 在聊天栏逐行列出库存 |
| `/ci Sync` | 从数据库强制同步云仓数据 |

## 容量与限制

- 按**物品类型**存储，数量为小数精度；每种物品存量上限 **64 组**（64 堆叠物即 4096 个，16 堆叠物即 1024 个）。
- 只收**默认形态**物品：带自定义名称、附魔、耐久损伤或特殊数据的物品无法入库（会被退件）。
- 单次取出上限：命令参数上限 **1728**，服务端上限 37 组，两者取小。
- 潜影盒可以整盒入库（盒内合规物品一并入库）；`GetBox` 只消耗普通潜影盒。
- 无冷却；数据采用缓存 + 每 2 秒批量落库，异常时用 `/ci Sync` 手动兜底。

## 费用与退件

- `/ci Put` 要求携带 **≥100 金币**（作为退件邮费担保）。
- 提交了无法入库的物品：通过邮箱退回并**收取 50 金币**手续费；金币不足时物品**直接丢失**——存东西前先确认物品是「干净」的。
- 取出时若背包放不下：在自己有权限的岛上直接掉落在原地；否则（普通档案且金币 ≥50）扣 50 金币寄到邮箱；都不满足则物品留在云仓，提示空间不足。

## 档案（Profile）隔离

云仓按「云仓档案」隔离，档案名取当前岛屿的云仓档案设置，未设置时取岛屿的普通档案：

- 常规岛屿与粘液空岛、超级空岛共用 `default` 云仓——**粘液空岛可以把普通模式的库存带进去用**。
- 专家模式各档案的云仓互不相通。

## 界面玩法

- 列表页：每行显示「★名称 ×数量」，可点 `[1]`/`[16]`/`[64]` 快捷取出、`[置顶]`、`[更多]` 进入详情页。
- 详情页：置顶开关、自动填充开关、取出 1/16/64、取出一盒、填满背包。
- 排序规则：置顶 → 最近使用 → 创建时间。

## 小贴士

- 自动填充是建筑党的神器：开启后，手持材料挖空一格就自动从云仓补上，配合[自动铺路](/guide/mechanics/便利功能#自动铺路)铺路几乎不用停手。
- 大批量转运时用 `GetBox` 一盒一盒地取，比一组一组快得多。
