# 岛屿开关

梦幻之屿的特性分两层控制：**整岛开关**（写在岛屿上，影响所有在岛玩家，由岛主切换）与**个人开关**（只影响自己，用 `/assist` 切换）。本页是全部开关的集中总览——游戏内还可以用 `/menu feature` 打开「特性列表」逐项查看与切换。

## 操作入口

- **整岛开关**：岛主使用下表中的命令，或在**岛屿设置**界面操作（从岛屿详情进入；`/openDialog /islands` 或 `/land of <玩家>` 打开岛屿详情）。
- **个人开关**：`/assist <开关名> true|false`，或辅助功能界面 `/assists` 中切换。
- **查看说明**：`/menu feature` 列出当前岛屿全部特性与说明。

## 整岛开关与命令

### 常规开关

| 命令 | 效果 | 备注 |
| --- | --- | --- |
| `/ToggleAntiFire` | 岛屿完全防火 | 仅切换已有 flag，首次开启请用岛屿设置界面（消耗 1 海洋之心） |
| `/ToggleAntiPhantom` | 不生成幻翼 | 首次开启消耗 1 海洋之心，之后切换免费 |
| `/ToggleDisableCreeperExplode` | 苦力怕爆炸不破坏方块 | |
| `/ToggleDisableNaturalSpawning` | 关闭自然生物刷新 | |
| `/ToggleDisableNeeko` | 是否允许在本岛使用[幻形](/guide/mechanics/幻形) | |
| `/ToggleAllSlimeChunk` | 全岛皆为史莱姆区块 | |
| `/ToggleSpectatorVisitor` | 非成员进岛自动进入旁观模式 | |
| `/ToggleAllowItemPickup` | 允许游客拾取物品 | |
| `/ToggleAllowItemDrop` | 允许游客丢弃物品 | |
| `/ToggleAllowFirework` | 允许游客放烟花 | |
| `/ToggleDisableEntityProtect` | 关闭「游客实体保护」（允许游客交互、攻击、骑乘实体） | |
| `/ToggleMcmmo` | 是否允许本岛 MCMMO 加成 | |

### 白名单管理

| 命令 | 效果 |
| --- | --- |
| `/AllowInteractBlocks add\|remove <方块>` | 允许游客交互的方块白名单 |
| `/AllowUseItems add\|remove <物品>` | 允许游客使用的物品白名单 |

### 岛屿设置

| 命令 | 效果 |
| --- | --- |
| `/NameSet <名称>` | 设置岛屿名称 |
| `/IconSet` | 用副手物品设置岛屿图标（消耗 1 个） |
| `/home set` / `/home reset` | 设置/恢复岛屿出生点 |
| `/BiomeSet <群系>` | 设置当前维度全岛的单一群系 |
| `/Lock Lock` / `/Lock Unlock` | 闭关锁岛/重新开放 |
| `/Member Add\|Remove\|List` | 管理岛屿成员（Add 需对方确认） |
| `/blacklist add\|remove\|list` | 管理岛屿黑名单 |
| `/TeleportationScaleSet <1\|8>` | 下界传送比例（只接受 8 或 1） |
| `/toggleRelocateEndPortal` | 是否把末地门出口重定向到本岛 |
| `/CobbleGenOres` | [刷石机出矿](/guide/mechanics/刷石机出矿)开关 |
| `/BeaconTeleport` | [信标传送](/guide/mechanics/便利功能#信标传送)开关 |
| `/HexBeacon enable\|disable <效果>` | 全岛信标效果（可选：速度、急迫、力量、跳跃提升、抗性提升、生命恢复）；**每个效果首次解锁消耗 1 海洋之心**，之后启停免费 |
| `/RegionStructure add\|clear\|list` | 在选区（用箭矢左右键选两点）生成结构：前哨站/女巫小屋/海底神殿（主世界）、下界要塞/堡垒遗迹（下界） |
| `/EnableCarpet` | [海底求生](/guide/islands/海底求生)专属：完成全部挑战后开启[李芒果机制](/guide/mechanics/李芒果机制) |

辅助功能界面里还有一批纯界面开关：TPS 栏、血量条、各种提示条与侧边栏、岛屿聊天前缀、旧版菜单等。

## 环境与生成设置

以下为岛屿级生成配置，均由岛屿类型预设，普通玩家一般不可改（管理端可通过 `/isa addFlag` 设置）：

| 设置 | 含义 | 启用示例 |
| --- | --- | --- |
| GeneratorSettings（6 项） | 噪声地形/地表/洞穴/装饰/生物/结构六项生成开关 | SMP 全开；海底求生只开结构 |
| GenerateStructures | 只开结构生成 | 困难空岛、海底求生、惊变 |
| LevelSingleBiomes | 三纲维度单一群系（见 `/BiomeSet`） | 常规岛屿；地底世界移除 |
| EnableEndGen | 末地完整地形生成 | 仅海底求生 |
| TeleportationScale | 下界传送比例（默认 1:8） | 常规岛屿；地底世界移除 |

岛屿时间、岛屿天气、随机刻速度（`RandomTickSpeed`）虽有实现，但**没有任何玩家命令**，只在活动/管理场景使用。

## 已实现但未开放的开关

以下特性代码已实现，但当前**没有挂载到任何常规岛屿类型**，普通玩家无法启用，列在此处仅供了解（管理端可为活动岛手动开启）：

| 类别 | 特性 |
| --- | --- |
| 方块控制 | 禁止破坏/放置方块、禁止方块燃烧/消退/形成、禁止珊瑚死亡、禁止冰/雪融化、禁止火焰蔓延与熄灭、禁止树叶凋零、禁止液体流动、禁止物理更新 |
| 实体控制 | 禁止生物生成、禁止实体生成、禁止怪物生成、禁止爆炸、禁止 PvP、禁止鞘翅、禁止玩家投掷物、禁止随机巡逻队、禁止骷髅陷阱、禁止海龟蛋孵化、禁止流浪商人生成 |
| 世界控制 | 禁止红石、区域群系（`/RegionBiome`）、全岛单结构（`/StructureSet`）、高级发射器（`/ToggleSuperDispenser`）、随机复活点、Tab 列表隐藏 |
| 功能类 | 自动补种、经验泳池、岛屿飞行、随机烟花、服务器资源包推送、区块刷新器 |
| 安全类 | 封岛（带理由）、区域 CPU 限时、禁止区块存盘 |
| 其他 | 信任所有人（管理端）、区域系统 `/district`、海岛结构放置的完整额度体系 |

其中「禁止骷髅陷阱」「全岛单结构」「高级发射器」「区域群系」存在命令但当前调用会提示不可用。

## 管理端

管理员可用 `/isa`（权限 `isletopia.isa`）直接读写任意岛屿的 flag、封岛/解封、设置岛屿标题、发放结构额度等；Web 后台也有等价的 flag 读写接口。
