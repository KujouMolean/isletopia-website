# 群内小游戏 · 挖矿

挖矿是一个「每天一次、连续升级」的轻量玩法：每天在群里 `/挖矿` 一次，镐子等级 +1，挖矿的收成随等级提高；断签会降级。等级足够高后，有机会挖出全服唯一的硬通货——**海洋之心**。

## 一、游玩流程总览

1. **前置条件**：完成 QQ 绑定（见[QQ 机器人绑定系统](qbot-bind.md)）。指令在 **QQ 群与 QQ 频道**均可用。
2. **每天挖一次**：发送 `/挖矿`。每天 1 次，按服务器时间跨天刷新。
3. **结算**：本次收成由「品质额度」决定，额度 = **10 + 挖矿前的等级**，额度越高能挖到的矿物越好。奖励以**游戏内邮件**发放（游戏内 `/assist mailbox` 领取）。
4. **升级**：挖完等级 +1（上限 100）。连续每天挖，镐子从木镐一路升到下界合金镐。
5. **断签**：跳过 n 天没挖，等级下降 n−1 级（在下一次挖矿时结算，先降后加）。

## 二、等级与镐子

- 等级区间 **0–100**，每次成功挖矿 +1，满级后提示「你的镐子已达到满级！」。
- 镐子名称按等级分档（仅是称号，不是实体物品）：

| 等级 | 镐子 |
|---|---|
| 0–10 | 木镐 |
| 11–20 | 石镐 |
| 21–30 | 铜镐 |
| 31–40 | 铁镐 |
| 41–50 | 金镐 |
| 51–60 | 钻石镐 |
| 61–100 | 下界合金镐 |

> 断签降级会在你下次真正挖矿时才结算，`/挖矿 查看` 里显示的等级只是预览，不会单独触发降级。

## 三、挖矿收益规则

每次挖矿的收成由**品质额度**决定：

- **额度 = 10 + 挖矿前的等级**，等级越高额度越大。
- 系统在矿物中随机挑选：抽中的矿物只要品质不超过剩余额度，就归你所有并扣掉对应额度，然后继续抽下一件。
- 越稀有品质越高——钻石（10）、远古残骸（15）、海洋之心（70）都会大口吃掉额度；额度不够时系统会跳过它，直到额度用尽。
- 因此每次挖矿必然有产出（最普通的石头永远挖得起），而稀有矿物只有在额度充裕时才可能出现。

**每件矿物的数量**由品质决定：

| 品质 | 单次数量 |
|---|---|
| 1–2 | 1–5 |
| 3–5 | 1–4 |
| 6–8 | 1–3 |
| 9–10 | 1–2 |
| 11 及以上（远古残骸、海洋之心） | 固定 1 |

## 五、海洋之心

海洋之心品质高达 70，只有剩余额度 ≥ 70 时才可能出现。由于首次额度 = 10 + 挖矿前等级，**挖矿前等级达到 60（即第 61 次连续挖矿）才第一次有机会挖到海洋之心**，等级越高机会越大。

参考概率（非保底）：60 级约 **4%**，70 级约 **16%**，90 级约 **33%**，满级 100 级约 **41%**。

## 六、命令一览

| 命令 | 说明 |
|---|---|
| `/挖矿` | 执行当日挖矿 |
| `/挖矿 查看` | 当前镐子与等级、累计次数、上次挖矿日期、今日状态 |
| `/挖矿 统计` | 总次数 + 最近 7 天的每日产出记录 |
| `/挖矿 帮助` | 帮助文本 |

当天重复挖矿会回复：`你今天挖过了，明天再挖。`
