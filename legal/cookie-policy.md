# Cookie 政策

> 最后更新：2026年10月2日

本政策说明"梦幻之屿"官方宣传网站（以下统称"本站"）如何使用 Cookie 及类似技术（如 localStorage、会话标识等）。

## 一、什么是 Cookie

Cookie 是网站访问过程中存储在您浏览器中的小型文本文件，用于记录偏好、维持会话状态或统计访问数据。类似技术还包括 localStorage、sessionStorage 等。

## 二、本站自身的 Cookie

- 本站为非经营性宣传站点，不提供注册、登录功能，不使用追踪类 Cookie，不进行跨站行为追踪。
- **本站自身仅设置下表所列的一项功能性 Cookie**（第一方），用于保存您在站内的个人偏好：

| Cookie 名称 | 所在页面 | 用途 | 存储内容 | 有效期 |
|---|---|---|---|---|
| `rc_favorites` | [合成表](/crafting) | 记住您收藏的配方，使收藏列表在多次访问之间保留 | 您收藏的配方 ID 列表（仅为本站内的配方标识符，不含任何个人身份信息） | 1 年 |

该 Cookie 仅在您使用合成表收藏功能时写入，采用 SameSite=Lax 策略，不用于识别您的身份，也不与任何第三方共享。
- 本站另使用 localStorage（浏览器本地存储）保存动态页的布局偏好（视图模式与筛选类型），该数据仅保存在您的浏览器本地，不传输到任何服务器。
- 访问本站产生的必要访问信息（如 IP 地址、访问时间）由托管与防护服务商以服务器日志形式记录，详见[《隐私政策》](/legal/privacy-policy)。

## 三、第三方服务可能设置的 Cookie

以下第三方服务可能按其自身政策在您的浏览器中设置 Cookie 或采用类似技术：

- **Cloudflare（内容分发与安全防护）**：可能设置用于安全、性能与站点防护的 Cookie。
- **GitHub / GitHub Pages（网站托管）**：访问与使用 GitHub Pages 相关功能时，相关 Cookie 按 GitHub 政策设置。
- **不蒜子（busuanzi，访问统计）**：本站页脚展示累计访问次数与访客数的聚合统计，该服务可能按其自身机制记录访问信息用于聚合统计。

上述服务设置 Cookie 的具体用途与处理方式，以各服务提供方官方公布的隐私政策为准（链接见[《隐私政策》](/legal/privacy-policy)第三条）。

## 四、如何管理 Cookie

- 您可以通过浏览器设置查看、删除或拒绝 Cookie（包括拒绝第三方 Cookie）。
- 删除或禁用 Cookie 后，合成表页面的收藏列表将无法保留，本站其余基础浏览功能不受影响。

## 五、政策更新

本政策可能随本站使用的第三方服务变化而更新，更新后的政策自发布之日起生效。如本站未来引入访问统计、评论等新服务，将相应更新本政策。
