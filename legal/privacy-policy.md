# 隐私政策

> 最后更新：2026年10月2日

本政策说明"梦幻之屿"官方宣传网站（以下统称"本站"）如何处理访客的数据。本站为非经营性宣传站点，本政策的核心事实是：**本站不主动收集您的个人身份信息**；本站使用的少数第三方服务可能按其自身政策处理您的部分数据。

## 一、我们收集什么

- **本站自身**：不提供注册、登录、表单或任何主动收集个人身份信息的途径，不收集姓名、邮箱、位置等个人身份信息。
- **访问日志**：为安全与故障排查需要，托管服务商（GitHub Pages、Cloudflare）会以日志形式记录必要的访问信息（如 IP 地址、访问时间、用户代理、所请求的页面），仅用于保障服务运行与安全。
- **访问统计（不蒜子 busuanzi）**：本站页脚展示的累计访问次数与访客数由第三方开源统计服务不蒜子提供，其可能按其自身机制处理您的 IP 地址等信息用于聚合统计，不收集可识别个人身份的信息。

## 二、Cookie

本站对 Cookie 及类似技术的使用详见[《Cookie 政策》](/legal/cookie-policy)。

## 三、第三方服务与数据出境

本站由 GitHub Pages（GitHub, Inc.）托管，并由 Cloudflare（Cloudflare, Inc.）提供全球内容分发与安全防护。您的访问请求与相关数据可能经由位于您所在国家或地区以外的服务器接收与处理。相关第三方服务的主要法律文件（均为官方公布版本）：

**GitHub（GitHub, Inc.）**

- GitHub 服务条款（含 GitHub Pages 相关条款）：<https://docs.github.com/zh/site-policy/github-terms/github-terms-of-service>
- GitHub 隐私声明：<https://docs.github.com/zh/site-policy/privacy-policies/github-privacy-statement>
- 关于 GitHub Pages（含访客数据收集说明）：<https://docs.github.com/zh/pages/getting-started-with-github-pages/about-github-pages>

**Cloudflare（内容分发与安全防护，Cloudflare, Inc.）**

- Cloudflare 网站服务条款：<https://www.cloudflare.com/website-terms/>
- Cloudflare 隐私政策：<https://www.cloudflare.com/zh-cn/privacypolicy/>

**不蒜子（busuanzi，访问统计）**

- 开源聚合统计服务（统计接口域名为 busuanzi.ibruce.info），本站仅使用其页脚计数功能，详见上文"一、我们收集什么"中的说明。

## 四、信息安全

本站依赖 GitHub 与 Cloudflare 提供的传输加密（HTTPS）与安全机制保护您的访问安全。任何互联网传输方式均无法保证百分之百安全，请您自行注意保护个人信息。

## 五、未成年人

本站不面向未成年人提供定向服务。如您为未成年人，请在监护人陪同下访问本站，并在对外提供任何个人信息前征得监护人同意。

## 六、政策更新

本政策可能随本站使用的服务变化而更新，更新后的政策自发布之日起生效，请以页面"最后更新"日期为准。

## 七、联系我们

如您对本政策或本站的数据处理方式有任何疑问，请通过邮箱 support@play.molean.com 联系服务器团队。
