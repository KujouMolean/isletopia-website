# 幻形

幻形（Neeko）是梦幻之屿的招牌系统：把玩家变身成其他生物的形象。全服共 90 种可幻形形象（含玩家本体），每种形象都有独特技能，还可以通过升星不断强化。全部形象的获取方式与逐星技能明细见[幻形图鉴](/wiki/特殊功能/幻形图鉴)。

## 操作与输入约定

- `/neeko`：打开幻形菜单，查看已拥有的形象并变身；
- `/neeko use <形象> [星级]`：直接变身；不填星级时按你的最高等级（等同满级预览）；
- `/neeko upgrade <形象>`：升星，**每级消耗 1 颗海洋之心**（弹确认框，优先消耗未收藏、不可交易的海洋之心）；
- `/neeko clear`：变回玩家。

图鉴中的技能缩写对应以下操作：

- **FF**：双击换手键（默认 F），两次间隔不超过 1 秒；
- **SS**：双击潜行键（Shift）；
- **SFF**：潜行状态下双击换手键；
- 部分技能用**右键**触发（手持特定物品或对特定目标）。

技能冷却与消耗由各形象自行实现，消耗通常是经验值或饱食度，不足时会在动作栏提示。

## 变身与解除

- 变身的检查顺序：该形象是否开放 → 所在岛屿是否允许幻形 → 是否已拥有；
- **岛屿限制**：进入未启用幻形的岛屿（如粘液科技空岛、超级空岛、专家模式岛屿）时，幻形会被立即解除并提示「当前岛屿无法使用幻形」；离开后按存档自动恢复。岛主切换开关的瞬间，岛内所有玩家同步生效；
- **死亡重生**后自动恢复原形象；**退出游戏**时解除，但形象与星级记录在案，**重新登录后自动恢复**（登录后约 5 tick 生效）；
- 「玩家本体」是一种特殊形象：不做任何外观替换，保持你自己的皮肤与模型，是默认形态。

## 形象获取

形象通过游玩中的「发现」解锁，每种形象有自己的途径与概率（见[图鉴](/wiki/特殊功能/幻形图鉴)逐条列出）。判定规则：

- 每个获取途径触发时，若你**已拥有**该形象则直接跳过；
- 首次触发未成功时**不会**在本次会话中反复累积判定（一次判定未命中后，同会话内不再重复）；
- [绵羊幻形](/wiki/特殊功能/幻形图鉴)的幸运度可以提升大多数「发现」的概率（绵羊条目见图鉴 061）。

管理员可用 `/neeko admin unlock <形象>` 为玩家解锁；`/neeko admin unlock all` 可一次解锁全部形象并升到 +6（无玩家入口）。

## 星级

- 每种形象**独立计级**，范围 0–6 星，最高 6 星；
- 0 星即有初始技能；每升 1 星解锁或强化一档技能；
- 升星成功后提示「请重新使用该形象」——新的星级在下次变身时生效；
- 升星需消耗海洋之心，这是长期投入，建议优先给主力形象。

## 绵羊的概率修正（深度机制）

绵羊是唯一能影响**全局随机事件概率**的形象，规则如下：

- 触发条件：幻形为绵羊且达到 2 星以上；
- 修正强度由「当前羊毛颜色」与「今日[幸运色](/wiki/特殊功能/幸运色)」的色差决定：色差越小修正越强（色差 <50，5 星后 <75）；
- 每次修正消耗经验（经验不足时提示并退回原概率）；
- 修正方向分两类：**提高**有利事件概率、**降低**不利事件概率。

受绵羊影响的完整清单：

| 机制 | 方向 |
| --- | --- |
| [幻形](/wiki/特殊功能/幻形)「发现」获取概率 | 提高 |
| 苦力怕论坛贡献奖励中的信标/收纳袋/海洋之心/鞘翅掉落 | 提高 |
| [幻翼掉鞘翅](/wiki/资源获取/特殊生物与掉落)（1%） | 提高 |
| 末地钓鱼钓到鞘翅（0.2%） | 提高 |
| [祈愿池](/wiki/特殊功能/祈愿池)损毁概率 | 降低 |
| [回响扳手](/wiki/便利功能/回响扳手)碎片消耗概率 | 降低 |

另外，绵羊的羊毛颜色还可以通过右键染料随时调整（1 星起），每天可重投一次幸运色（4 星）。

## 幻形与其他系统的联动

幻形不只是外观，多个系统会读取你的形象：

- **头颅掉落**：高星苦力怕幻形自爆可引爆生物并掉落对应头颅（见[特殊生物与掉落](/wiki/资源获取/特殊生物与掉落)）；
- **云仓**：4 星潜影贝幻形副手持潜影盒时，周期性把背包物品上传云仓；5 星起放置方块优先从云仓扣除；
- **[幸运色](/wiki/特殊功能/幸运色)**：皮革减伤只在「玩家本体」形态下生效；
- **空岛配方**：岛上有任意等级悦灵幻形玩家时，可烧制「泥土 → 灵魂土」（见[空岛合成配方](/wiki/资源获取/空岛合成配方)）；
- **飞行与天气**：蝙蝠、恼鬼、鹦鹉幻形拥有各自的飞行方式；溺尸幻形的环境永远下雨等；
- **全岛信标**：6 星鹦鹉幻形可让[全岛信标](/wiki/便利功能/岛屿开关#全岛信标)效果等级 +1；
- **任务**：挑战任务中有专门要求幻形相关的目标。

## 可见性说明

幻形通过改写发送给客户端的实体数据实现（服务端替换模型），**需要客户端版本达到 1.21.8 以上的协议版本**才能看到其他玩家的伪装外观；版本较低的客户端看到的仍是普通玩家——这不影响技能效果，只是看不到外观。

## 已知边界

- 界面上可能显示个别未开放形象（末影龙、玩家模型），点击会提示「该形象尚未开放」；
- 星级上限固定为 6，与个别形象实际可用的星级数量无关；
- 具体技能数值以[图鉴](/wiki/特殊功能/幻形图鉴)为准，个别技能标注了「未实装」。
