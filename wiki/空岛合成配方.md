# 空岛合成配方

空岛合成配方（SkyblockRecipe）是一整套为空岛资源闭环设计的自定义配方，共 80 余条，覆盖矿石还原、泥土沙类转化、树苗循环、烈焰棒等原版空岛中难以获取的资源。
这些配方只在开启了该特性的岛屿上生效；未启用的岛屿上合成或烧制会被取消（「泥土烧灵魂土」一条不受该开关约束，只要求岛上有悦灵幻形）。

## 合成配方查询方法
 - 游戏内输入查询指令 `/menu recipe`
 - 本站提供在线版合成表 [>>合成配方查询<<](/crafting)

- 沙子 → 砂砾 → 圆石与圆石 → 砂砾 → 沙子两条链可以互相转化，配合刷石机实现三种建材的循环。

## 矿石还原（工作台·有序）

通式：**8 份资源围一圈 + 中心 1 个基底方块 → 1 个矿石**。基底为石头时得到普通矿石，基底为深板岩时得到深层矿石，下界矿石使用下界基底。

| 成品 | 8×资源 | 中心基底 |
| --- | --- | --- |
| 煤矿石 | 煤炭 | 石头 |
| 铁矿石 | 铁锭 | 石头 |
| 铜矿石 | 铜锭 | 石头 |
| 金矿石 | 金锭 | 石头 |
| 红石矿石 | 红石块 | 石头 |
| 青金石矿石 | 青金石块 | 石头 |
| 钻石矿石 | 钻石 | 石头 |
| 绿宝石矿石 | 绿宝石 | 石头 |
| 深层煤矿石 | 煤炭 | 深板岩 |
| 深层铁矿石 | 铁锭 | 深板岩 |
| 深层铜矿石 | 铜锭 | 深板岩 |
| 深层金矿石 | 金锭 | 深板岩 |
| 深层红石矿石 | 红石块 | 深板岩 |
| 深层青金石矿石 | 青金石块 | 深板岩 |
| 深层钻石矿石 | 钻石 | 深板岩 |
| 深层绿宝石矿石 | 绿宝石 | 深板岩 |
| 下界金矿石 | 金锭 | 下界岩 |
| 下界石英矿石 | 石英 | 下界岩 |
| 镶金黑石 | 金锭 | 黑石 |

配合时运镐，这套配方可以把锭类资源「存进」矿石里再放大产出。

## 其他工作台配方

有序配方：

| 成品 | 配方 |
| --- | --- |
| 远古残骸 | 8×骨块围圈 + 中心 1×下界合金块 |
| 蜘蛛网 | 9×线 |
| 黏土球 ×32 | 8×泥土 + 中心 1×粘液球 |
| 铁/金/下界合金/铜锭、红砖、下界砖 | 8×对应染料 + 中心任意 1 个上述六种锭/砖（互相转换） |

染料对应关系：白染料 → 铁锭、黄染料 → 金锭、黑染料 → 下界合金锭、橙染料 → 铜锭、红染料 → 红砖、棕染料 → 下界砖。

无序配方：

| 成品 | 材料 |
| --- | --- |
| 末地石 | 石头 + 末影珍珠 |
| 深板岩 | 石砖 + 煤炭 |
| 橡树树苗 | 2×深色橡树树苗 |
| 云杉树苗 | 2×橡树树苗 |
| 白桦树苗 | 2×云杉树苗 |
| 丛林树苗 | 2×白桦树苗 |
| 金合欢树苗 | 2×丛林树苗 |
| 深色橡树树苗 | 2×金合欢树苗 |

六种树苗首尾相连形成循环，配合骨粉与砍树可以任意转换树种。
