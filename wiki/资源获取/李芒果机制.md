# 李芒果机制

李芒果机制（CarpetModifications）是一整套借鉴 Carpet 模组与李芒果空岛（ilmango 系）思路的原版机制改造，让几乎所有资源都可再生。它在[困难空岛](/wiki/空岛类型/困难空岛)默认开启，[惊变空岛100天](/wiki/空岛类型/惊变空岛100天)同步启用；[海底求生](/wiki/空岛类型/海底求生)在完成全部挑战后可由岛主用 `/EnableCarpet` 解锁。

| 机制 | 效果 |

| 末影龙掉紫颂 | 末影龙 100% 掉紫颂果 ×16 + 紫颂花 ×4 |

| 末影人持草 | 末影人 10% 概率手持高草/大型蕨生成，击杀必掉（高草可再生） |
| 蜘蛛骑士掉网 | 蜘蛛骑士中先死亡的一半掉 1 个蜘蛛网 |

| 猪灵蛮兵掉残骸 | 玩家击杀猪灵蛮兵按抢夺等级 0–3 掉远古残骸，概率 5%/6%/7%/8% |
| 猫送附魔金苹果 | 猫的晨礼约 1.59% 概率为附魔金苹果 |
| 村民送岩浆桶 | 盔甲匠/工具匠/武器匠的英雄礼物按约 4.8%（武器匠 6.25%）替换为岩浆桶 |
| 恼鬼转悦灵 | 对带虚弱效果的恼鬼喂金苹果，转化为悦灵（继承名字） |
| 苦力怕掉唱片 | 骷髅击杀的苦力怕，在堡垒遗迹/要塞/远古城市/试炼密室 128 格内死亡时，分别掉 Pigstep、otherside、唱片碎片 5、Precipice/Creator |

| 狐狸叼甜浆果 | 狐狸生成时 20% 概率叼着甜浆果 |
| 监守者掉回响 | 监守者音波击杀海豚/蝙蝠时掉回响碎片 |
| 潜影贝重生 | 再次击杀末影龙后，出口传送门上方生成潜影贝 |
| 闪电点亮藤蔓 | 闪电击中荧石（或避雷针保护的荧石）时，邻接藤蔓变成发光地衣 |

> 守卫者升变（闪电击中守卫者→原地生成远古守卫者）由独立特性控制，在[困难空岛](/wiki/空岛类型/困难空岛)与常规岛屿上启用，惊变空岛100天与海底求生**不**包含，不随李芒果机制开关走。

## 岛屿配方

李芒果机制额外提供 3 条配方：甜浆果 + 荧光墨囊 → 发光浆果（无序合成）；安山岩高炉 → 凝灰岩；闪长岩高炉 → 方解石（100 tick，0.1 经验）。后两条与[空岛合成配方](/wiki/资源获取/空岛合成配方)中的同类配方并存。

## 结构放置额度

击杀末影龙后，若岛上还没有结构放置权限，会自动授予 **5 次结构放置额度**（每种结构 1 次），用于在专家模式下布置关键结构。
