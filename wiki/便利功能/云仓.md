# 云仓

云仓（CloudInventory）是跨岛屿、跨世界的云端仓库：把物资存进去，在任何开启云仓的岛屿上取出来，背包满了不用跑回家。它不是一个简单的背包，而是一套带有缓存的持久化存储系统——理解它的存取规则（哪些物品能进、上限怎么算、溢出怎么处理）能避免丢东西。

## 入口与前置

- 命令：`/cloudinventory`（别名 `/ci`、`/云仓`）。
- 前置：所在岛屿启用云仓特性（绝大多数常规岛屿默认启用；专家模式岛屿未启用）。
- 另有 GUI 入口：辅助功能界面（`/assists`）中的「云仓」。
- QQ 群内可用 `/云仓 [玩家]` 查看某玩家云仓的前 25 种物品（按数量降序，固定读取普通档案）。

## 命令一览

| 命令 | 功能 |
| --- | --- |
| `/ci List`（或 `/ci GUI`） | 打开云仓列表界面 |
| `/ci Get <物品> <数量>` | 取出物品，命令参数范围 1–1728，服务端另有上限 |
| `/ci Put` | 打开 54 格「上传物品」容器，**关窗时结算入库** |
| `/ci Fill <物品>` | 用云仓库存把背包中的该物品补满（受背包空间与上限约束） |
| `/ci GetBox <物品>` | 消耗 1 个潜影盒 + 27 组该物品，产出一盒装满的潜影盒 |
| `/ci EnableAutoFill <物品>` | 开启自动填充（同时只能开启一种材料） |
| `/ci DisableAutoFill` | 关闭自动填充 |
| `/ci TogglePin <物品>`（别名 `pin`） | 置顶/取消置顶（置顶物品排最前，带 ★ 标记） |
| `/ci textList` | 在聊天栏逐行列出库存 |
| `/ci Sync` | 从数据库强制同步云仓数据 |

## 存储与同步机制

- **按「玩家 + 档案」隔离**：档案名取所在岛屿的云仓档案设置，未设置时取岛屿的普通档案。常规岛屿与粘液空岛、超级空岛共用 `default`——**粘液空岛可以把普通模式的库存带进去用**；专家模式各档案互不相通。
- 数量以**小数精度**存储，按物品类型累积；服务端以内存缓存为准，**每 2 秒批量落库**，异常时用 `/ci Sync` 手动从数据库重载。
- 首次访问某种材料时会同步加载数据；缓存采用懒加载、不主动卸载（`Sync` 是唯一的强制失效手段）。

## 存入：哪些物品能进

`/ci Put` 打开一个 54 格容器，**关窗时统一结算**。要求携带 **≥100 金币**（作为退件邮费担保）。结算规则：

1. **普通物品**逐格校验「相似度」；
2. **潜影盒**特殊处理：盒子本身无条件入库（**彩色盒按自己颜色独立存为一种材料**，且不受 64 组上限约束）；盒内 27 格逐格按普通物品校验，能进的进云仓，不能进的进退件；
3. **无法入库的物品**通过邮箱退回并**收取 50 金币**手续费；金币不足时物品**直接丢失**。

**相似度判定**是云仓最容易被忽略的规则：只接受**默认形态**物品，比较的是「物品类型 + 完整数据组件」。因此：

- ✅ 可以存：白板方块、材料、**未损伤且无附魔无改名的白板工具**；
- ❌ 不能存：有任何耐久损耗、附魔、自定义名称、lore、皮革染色、药水内容、写入内容的书——都会被退件。

**64 组上限是软约束**：校验发生在提交前（拿的是提交前的库存量），所以：

- 恰好达到 64 组时仍可继续提交；
- 一次提交可以远超 64 组（如石头从零一次存入 54 组 × 64）；
- 一旦存量超过 64 组，该材料就**只能取出、不能再存入**。

## 取出：上限与溢出

取出的服务端校验顺序：岛屿开关 → 数量 >0 → 不超过 **37 组** → 库存足够。命令层再额外限制 1728；**界面按钮不受 1728 限制**，只受 37 组约束。实际单次上限：

| 物品堆叠 | 单次上限 |
| --- | --- |
| 64 堆叠（方块、材料） | 2368（命令最多 1728） |
| 16 堆叠（末影珍珠等） | 592 |
| 不可堆叠（工具） | 37 |

其他规则：

- `/ci Fill` 会扫描**整个背包**（含盔甲与副手），统计同类物品的剩余空间并补满，上限同样取 37 组与 1728 的较小值；
- `/ci GetBox` 固定消耗 1 个**普通潜影盒** + 27 组物品，产出一盒填充好的普通潜影盒；彩色盒不能替代消耗，也不能"盒套盒"；
- **取出时背包放不下**：在自己有权限的岛上直接掉落在原地；否则（普通档案且金币 ≥50）扣 50 金币把物品寄到邮箱；都不满足则提示空间不足、**物品留在云仓**；
- **注意**：如果取出瞬间你的存档档案发生切换，物品会被判定为「预期之外的错误」而没收（已扣除不退回）——换岛/换档案途中不要取件。

## 自动填充

开启后（`/ci EnableAutoFill <物品>`，**同时只能一种材料**）：

- **触发时机**：每秒轮询一次，另外在点击背包、右键交互、拾取物品时即时触发；
- **作用范围**：仅**快捷栏 0–8 格与副手**，不会补背包主区与盔甲；
- 把该范围内同类未满堆叠补满，从云仓扣除；
- **库存不足时自动关闭**并提示「补充失败，已关闭自动补充」——不会反复空刷；
- 适配建筑/挖矿场景：配合[自动铺路](/wiki/便利功能/自动铺路)，手里的材料挖空一格就自动补上。

## 界面玩法

- 新版列表页每页 **10 条**（旧版菜单每页 45 条）：每行「★名称 ×数量」，可点 `[1]`/`[16]`/`[64]` 快捷取出、`[置顶]`、`[更多]` 进入详情；
- 详情页：置顶开关、自动填充开关、取出 1/16/64、取出一盒、填满背包；
- 排序规则：置顶 → 最近使用 → 创建时间；
- 旧版菜单会额外显示物品的"价值"与"合计价值"（按全服总量估算）。

## 进阶：漏斗与投掷器桥接

自定义名称中包含「云仓」的**漏斗**会把吸入的物品直接存入云仓（按 64 个一批累积提交）；名称含「云仓」的**投掷器**则会从云仓取货发射（带预留机制）。这是给自动化场景准备的接口，普通玩家日常用命令即可。

## 已知边界

- 帮助文案中「每种物品需海洋之心解锁后才能提取」的说法在当前版本**没有实现**，实际不需要解锁；
- 白板工具存入后取出的是**全新默认实例**，存前请确认工具没有耐久或附魔（有则会被退件）。

## 小贴士

- 大批量转运时用 `GetBox` 一盒一盒地取，比一组一组快得多。
- 存贵重物品前先确认它是"干净"的：无附魔、无改名、满耐久，否则要么被退件扣 50 金币，要么金币不足直接丢失。
