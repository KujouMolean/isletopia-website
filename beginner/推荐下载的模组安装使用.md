# **一、Simple Voice Chat（简单的语音聊天）下载安装使用**

## **1.下载**

### **下载方式1：**

CurseForge: https://www.curseforge.com/minecraft/mc-mods/simple-voice-chat

![1789288166037](/images/1789288166037.png)

All Game Versions: 选择对应你游戏版本的文件

All Mod Loaders:选择你的模组加载器

完成后点击Download File，等待下载完成即可。

### **下载方式2：**

Modrinth: https://modrinth.com/plugin/simple-voice-chat

![1789288174251](/images/1789288174251.png)

Select game version: 选择游戏版本

Select platform: 选择客户端平台

完成后点击Download，等待下载完成即可。

### **下载方式3：**

如上述两个网站无法打开，可[加入QQ群](../../join-us.md)(梦幻之屿-综合交流)寻求帮助。

## **2.安装**

在电脑中找到.minecraft文件夹，将下载好的文件拖到mods文件夹内即可。

如果开启了各版本隔离，则需要在versions文件夹内找到要安装的游戏版本，点开文件夹后将模组拖到mods文件夹内。

## **3.使用**

当进入服务器时，会自动加入当前岛屿群组，只需设置键位即可与同岛玩家语音。

![1789288180824](/images/1789288180824.png)

下载完成打开游戏后默认键位绑定

键位绑定完成后，进入游戏按下[通话设置]绑定的快捷键可以打开通话设置界面

![1789288187281](/images/1789288187281.png)

调整完成后，点击左侧麦克风图标，按住[通话键]绑定的快捷键可以测试麦克风是否可以正常使用。

# **二、REI（Roughly Enough Items）下载安装使用**

虽然服务器内可以通过指令/menu recipe查看特殊合成表，但这存在一定滞后性，如想查看最新的合成表，请使用该模组。

当前该模组仅可在26.1.2使用，1.21.2后所有合成配方均储存在服务端

## **1.下载**

### **下载方式1：**

CurseForge: https://www.curseforge.com/minecraft/mc-mods/roughly-enough-items

![1789288200377](/images/1789288200377.png)

All Game Versions: 选择对应你游戏版本的文件

All Mod Loaders:选择你的模组加载器

完成后点击Download File，等待下载完成即可。

### **下载方式2：**

Modrinth: https://modrinth.com/mod/rei

![1789288206915](/images/1789288206915.png)

Select game version: 选择游戏版本

Select platform: 选择客户端平台

完成后点击Download，等待下载完成即可。

### **下载方式3：**

如上述两个网站无法打开，可前往QQ群：824852529(梦幻之屿-综合交流)寻求帮助。

## **2.安装**

在电脑中找到.minecraft文件夹，将下载好的文件拖到mods文件夹内即可。

如果开启了各版本隔离，则需要在versions文件夹内找到要安装的游戏版本，点开文件夹后将模组拖到mods文件夹内。

## **3.使用**

安装完毕进入游戏后，打开背包可以看到右侧多了一栏。

![1789288213252](/images/1789288213252.png)

在底部搜索栏输入物品名可以搜索物品

将鼠标指针悬浮在物品上按R查看配方，按U查看用途
